# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## À propos

AutoLoc est une étude de cas développée dans le cadre du module **UP ASI — Architecture des Systèmes d'Information** à l'ESPRIT. L'objectif est de concevoir et développer une plateforme permettant à plusieurs agences de gérer la location de véhicules : réservations, disponibilité des véhicules, clients, etc.

## Acteurs identifiés

- **Client** : consulte les véhicules disponibles, effectue des réservations, gère son historique de location.
- **Agent d'agence** : gère les réservations au quotidien, enregistre les retours de véhicules, met à jour la disponibilité.
- **Responsable d'agence** : supervise les agents, consulte les statistiques de l'agence, valide certaines opérations.
- **Administrateur** : gère les comptes utilisateurs, configure les agences, a une vue globale sur la plateforme.

## Stack technique

- Java 17, Spring Boot, Spring Data JPA
- MySQL
- Maven
